**BlinkMod** — клиентская модификация для Blink со встроенным нативным оверлеем управления геолокацией, приватностью, кастомизацией телеметрии шагов, виджетами и автоматическими турами по странам мира.

> Проект не связан с официальной командой Blink. Репозиторий содержит исключительно открытый код и ресурсы оверлея BlinkMod. Проприетарные ресурсы оригинального приложения в репозиторий не входят.

## Основные возможности

### Приватность и геолокация
- **Интерактивный выбор точки (MapPicker)**: выбор любой точки на карте в реальном времени.
- **Округление позиции**: размытие координат до ~100 м или ~1 км перед сетевой отправкой.
- **Интервал отправки и полная пауза**: настраиваемый троттлинг запросов (`POST /api/geo/android`).
- **Скрытие заряда батареи**: фиксация любого процента (1–100%) либо передача `null`.

### Мировое турне и Топ-1 мира
- **Физика автомобильного движения**: перемещение со скоростью ~50 км/ч ($13.8$ м/с) с плавным поворотом дуги (bearing). Активирует статус поездки на машине у аватара на карте и гарантирует зачисление страны бэкендом Blink.
- **Синхронизация посещенных стран**: считывание локального кэша `dir_world_footprints` и прямое сопоставление с базой 232 стран.
- **Динамический рейд по недостающим странам**: автоматический проезд только по тем странам, которых ещё нет в профиле.
- **Снайпер ТОП-1**: гарантированное взятие первого места мирового лидерборда.

### Шаги и активность
- Быстрое действие на 100 000 шагов (`force_100k_once`).
- Множитель штатной синхронизации (`x1..x10`).
- Локальный визуальный множитель отображения дистанции.

### Интерфейс и виджеты
- AMOLED-режим, компактная разметка, переключение расположения плавающей кнопки.
- Виджеты рабочего стола: «Карточка друга» и радар «Кто рядом».
- Blink Lab: проверка API, локальный журнал событий, поиск пользователей по ID/username.

## Сборка оверлея

```bash
# Режим разработчика (со всеми инструментами Топ-1 и Blink Lab)
./scripts/build-overlay.sh dev

# Публичный режим (безопасный релиз со скрытым Dev-инструментарием)
./scripts/build-overlay.sh public
```
