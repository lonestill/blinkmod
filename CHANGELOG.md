# Changelog

## 1.1.0

- Интерактивный выбор точки спуфинга прямо на карте Blink (MapPicker) без ручного копирования координат.
- Динамическая система бейджей пользователей из GitHub (`badges.json`) по Account ID и username.
- Отображение бейджа в профиле пользователя и в меню настроек BlinkMod.
- Оптимизировано кеширование бейджей (30 сек + обход CDN-кеша).
- Бамп версии мода до 1.1.

## 1.0.0

- Первое публичное издание BlinkMod.
- Нативное меню настроек.
- Управление шагами и приватностью.
- Настройки интерфейса и плавающей кнопки.
- Виджеты друга и ближайших друзей.
- Инструменты профиля, чатов, поиска и навигации по ID.
- Blink Lab и экспорт конфигурации.
- Один universal ARM64 APK.
