# BlinkMod 1.0

Первый публичный релиз BlinkMod.

## Основное

- управление шагами и быстрое действие на 100 000;
- настройки геолокации и передаваемого заряда;
- AMOLED/compact UI и настройка кнопки BlinkMod;
- виджеты друга и ближайших друзей;
- инструменты чатов, друзей, профилей и навигации по ID;
- Blink Lab и резервная копия конфигурации;
- один universal APK для ARM64.

## Требования

- Android 12+
- ARM64
