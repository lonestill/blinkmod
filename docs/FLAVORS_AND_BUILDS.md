# Варианты сборки BlinkMod (Public vs Dev)

BlinkMod разделен на два режима функционирования: **публичный релиз (Public)** и **версия для разработки / закрытого тестирования (Dev)**.

Разделение необходимо для защиты ключевых исследовательских функций (массовая накрутка стран мира, прямой доступ к закрытым эндпоинтам API Blink) от публичной огласки и оперативного патчинга со стороны разработчиков Blink.

## 2. Секретная активация режима разработчика (Easter Egg)

В публичной сборке функционал разработчика по умолчанию отключен. Чтобы открыть полный Dev-функционал в установленном приложении:

1. Откройте меню **BlinkMod** через плавающую кнопку.
2. В главном меню найдите блок вверху: **BlinkMod (версия 1.2.0)**.
3. Быстро нажмите **5 раз подряд** по строке с названием и версией.
4. Появится всплывающее уведомление: `⚡ Режим разработчика включён!`.
5. Главный экран мгновенно обновится:
   - В разделе **ИНСТРУМЕНТЫ** появится **Blink Lab**.
   - В разделе **Приватность** → **Геолокация** в блоке «Мировое турне» появятся кнопки **«ВЗЯТЬ НЕДОСТАЮЩИЕ СТРАНЫ»** и **«СНАЙПЕР ТОП-1 МИРА»**, а также счетчик и список недостающих стран.
6. Повторные 5 нажатий возвращают приложение в безопасный публичный режим (`🔒 Режим разработчика выключен`).

## 3. Команды сборки и деплоя

### Сборка только оверлея DEX (`blinkmod_repo`)
Скрипт автоматически правит флаг `ModConfig.IS_DEV_BUILD`, компилирует байткод и синхронизирует готовые Smali в директорию APK:

```bash
# Сборка версии для разработчика (по умолчанию)
./scripts/build-overlay.sh dev

# Сборка публичной релизной версии
./scripts/build-overlay.sh public
```

### Полная сборка, подпись и установка APK на устройство
Скрипт выполняет полный цикл (сборка оверлея -> упаковка apktool -> выравнивание zipalign -> подпись apksigner -> установка через adb -> перезапуск приложения):

```bash
# Установка Dev-сборки на подключенный телефон
./build_and_deploy.sh AN7B6R5109001211 dev

# Установка Public-сборки на подключенный телефон
./build_and_deploy.sh AN7B6R5109001211 public
```
